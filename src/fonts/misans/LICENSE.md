# MiSans 许可

这些字体文件是小米公司的 MiSans 字体（MiSans VF，版本 4.009），按小米官方切片范围分块，来自 npm 包 `misans@5.0.0`，原样未改。

许可以小米官方《MiSans 字体知识产权许可协议》为准：
https://hyperos.mi.com/font-download/MiSans%E5%AD%97%E4%BD%93%E7%9F%A5%E8%AF%86%E4%BA%A7%E6%9D%83%E8%AE%B8%E5%8F%AF%E5%8D%8F%E8%AE%AE.pdf

要点（摘要，不代替原文）：
- 全球、非独占、免版税的免费商用许可，可以嵌入软件使用。
- 需要在软件中注明使用了 MiSans：WAswitch 写在“设置 › 关于”的“界面字体”一行。
- 不得改编、二次开发字体；不得单独出租、再许可或销售字体本身。
