MCP 接口

开启后，本机的 AI 客户端（Claude Desktop、Claude Code 等）可以列出账号、看未读数、切换、添加、改名和删除账号。读对话列表、找对话和读聊天消息要另外打开第二层，起草回复、辅助工具（话术、翻译、客户时间）、客户资料（搜索、修改）也要另外打开。不能发送消息。只接受本机连接，需要 token。

第二层：读对话

    
    
只读：不点开别的对话、不标已读、不保存到电脑。读到的内容会发给 AI 服务商。读消息一次最多 50 条；网页版账号只能读当前打开的那个对话，轻量版账号可以读任意对话。关着时 AI 看不到这个功能。
