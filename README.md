# WAswitch

在一个窗口里同时登录多个 WhatsApp 账号的桌面软件（Windows / macOS，Mac 只支持 Apple 芯片）。

维护文档：[问题记录与回归检查](docs/ISSUES.md)（已发现问题、修复依据和防止复发的检查要求）。

## 原理

基于 Electron。每个账号加载 `https://web.whatsapp.com`，并使用独立的 session 分区
（`persist:wa-<id>`），所以每个账号的 cookie、本地存储和登录状态完全隔离，关掉软件再打开也不用重新扫码。

为什么不做成纯网页：WhatsApp Web 禁止被 iframe 嵌入，而且同一个浏览器里的多个标签页共享同一份登录状态，
网页版无法真正“多开”。桌面应用没有这个限制。

## 安装

在 [Releases](https://github.com/Kr1xxxx/WAswitch/releases) 下载最新的安装包：Windows 用 `.exe`；macOS 用 `.dmg`（只支持 M 系列芯片）。

安装包没有做代码签名（需要付费证书），第一次打开时系统会拦一下：

- **Windows**：出现“Windows 已保护你的电脑”时，点“更多信息”，再点“仍要运行”。
- **macOS**（只支持 M 系列芯片）：把 WAswitch 拖进“应用程序”后，第一次在“应用程序”里**右键点 WAswitch → 打开**，再点“打开”。macOS 15 及以后右键打开不再放行：先双击一次（会提示无法打开），然后去 **系统设置 › 隐私与安全性**，在页面下方点“仍要打开”。如果提示“已损坏”，在终端运行 `xattr -cr /Applications/WAswitch.app` 后再打开。

只能同时运行一个 WAswitch，重复打开会直接显示已经开着的窗口。

### 自动更新

启动 1 分钟后检查一次，之后每小时检查一次，只连 GitHub，不走任何账号的代理。进度和上次检查的结果在 设置 › 关于。

- **Windows**：自动下载，下载完不用再点：自动静默安装并重新打开。正在打字或操作、编辑账号、扫码、发消息或页面还在加载时，等这些结束再装。点“立即更新”马上安装；点“稍后”改成窗口缩在托盘、没有未读、10 分钟没有新消息时再装，重启后回到托盘。退出软件时也会顺手装上。
- **macOS**：没有签名证书，不走系统自带的更新，由 WAswitch 自己替换。自动下载新版 `.zip` 并按 sha512 校验、解压、核对版本号；安装时机和 Windows 一样（下载完自动，或点“立即更新”）：WAswitch 退出后替换“应用程序”里的 WAswitch.app、清掉“已损坏”标记、重新打开。WAswitch 不在“应用程序”里（比如直接在安装盘里运行）或没有写入权限时，改成弹通知，点“打开安装包”后把新的 WAswitch 拖进“应用程序”。

开机自动启动：Windows 上会直接缩在托盘里；macOS 13 及以后系统不告诉软件是不是开机启动的，所以 Mac 上开机后会正常弹出窗口。

## 功能（当前版本）

- 左侧账号栏：显示名称、颜色、线路和未读数；左上角按钮可以收起成只显示图标
- 添加账号：起名、选颜色、设代理并测试，然后扫码登录
- 右键账号或点顶栏“⋯”：编辑、刷新、不弹通知、删除（清除这个号在本机的数据；手机的“已关联的设备”里需要手动退出）
- `Ctrl`（macOS 是 `Cmd`）+ `1` 到 `9`：切换到第几个账号
- 代理连不上时显示原因，并自动重试（10 秒起，最长每分钟一次）；电脑睡眠醒来后自动重连
- 设置页：内存、通知、通用（关闭窗口缩到托盘、开机自动启动、侧栏只显示图标）、隔离自检、关于
- 日志：每天一个文件，保留 7 天，只记录软件运行情况，不记录聊天内容和号码。设置 › 关于 › 打开日志文件夹
- 自带的新消息弹窗（屏幕右上角，不用系统通知）：写客户名字、哪个号收到的、最后一条消息，点「打开」切到那个号，「稍后」10 分钟后还没读再提醒；同一个客户合并成一张，最多同时 3 张；没动鼠标、没按键时不消失，离开电脑超过 5 分钟后要回来一张一张点掉；聊天锁定时不显示名字和内容；有自带勿扰（只挡新消息，号掉线这类提醒照弹）和提示音；每个号可以单独静音
- 托盘图标和总未读数：任务栏/Dock 显示所有账号的未读总数；关闭窗口会缩到托盘，后台继续收消息，从托盘菜单退出
- 主号和小号：第一个网页版账号默认是主号，可以在编辑账号里换。小号可以选“轻量模式”（见下文）

## 轻量模式（小号，试验功能）

添加账号时可以选“轻量模式”：不打开 WhatsApp 网页，而是在一个共用的后台进程里直接连接 WhatsApp，每个号只占几十 MB 内存（网页版每个约 300 MB）。基于开源库 [Baileys](https://github.com/WhiskeySockets/Baileys)（固定版本 7.0.0-rc14）。

**风险：轻量模式不是官方客户端，WhatsApp 可能识别出来并封号，通常发生在几天到几周内。请先用一个不重要的号连续试用两周，再考虑用在正式号上。** 主号只能用网页版，软件里不允许把主号设成轻量模式。

能做的：扫码登录、看对话列表、收发文字、未读数和通知（和网页版一样只显示“有 N 个未读对话”）。
暂时不能做的：图片、语音、文件只显示“[图片]”这类说明，内容请在手机上看；不能发图片；不能给没有对话的号码发消息。

安全和隔离：

- 可以直连（编辑页有一行风险提示，不拦）；设了代理（socks5 或 http）就要测试通过才能保存，出口 IP 不能和主号相同，和其他号相同时会提醒。
- socks5 代理一律让代理解析域名，本机不查询任何 WhatsApp 域名。
- 后台进程装了网络护栏：除了代理本身，任何连接、DNS 查询和 UDP 都会被拦下，所以即使某个功能漏了代理，也只会失败，不会暴露真实 IP。拦下的次数显示在隔离自检里。
- 不联网查询协议版本号（用 Baileys 内置的版本），不主动显示“在线”；只有点开对话时才发蓝色已读。
- 每个号每分钟最多发 10 条。
- 登录凭据和聊天缓存用 AES-256-GCM 加密后保存在本机；密钥用系统钥匙串加密。聊天缓存每个对话最多保留 500 条文字。
- 数据密钥绑定这台电脑的这个系统用户（系统钥匙串）。把数据文件夹复制到别的电脑、或换了系统用户后读不出来，只能删掉这个号重新添加、重新扫码。
- 手机上移除了设备，或 WhatsApp 拒绝连接（可能被封）时，停止自动重连，侧栏变红并弹通知。
- 删除轻量账号时会让手机“已关联的设备”里的这台设备一起退出。
- 聊天里的链接只允许 http、https、mailto、tel，用系统程序打开。

离线自检（不需要联网和账号，用本机假代理验证上面几条）：

```bash
npm run check:lite
```

## 账号隔离

每个账号在三个层面上彼此独立：

| 层面 | 做法 |
| --- | --- |
| 数据 | 独立的 cookie、登录状态、本地存储和缓存 |
| 网络 | 每个账号可以单独设置代理（socks5 / http）。代理连不上时这个账号断网，不会改用直连；WebRTC 也被限制为只走代理，不会泄露真实 IP。直连号可以单独打开“允许通话”（默认关） |
| 环境 | 每个账号的浏览器标识、时区按它的地区单独设置，时区与代理出口一致；WhatsApp 界面语言所有账号统一中文 |

用 Clash 给每个账号分配不同节点的方法，见 [docs/clash.md](docs/clash.md)。

带密码的代理，密码用系统钥匙串加密后保存在本机。

多个账号共用同一代理网关、但使用不同用户名时，认证按账号会话区分。无法确定所属会话的后台请求会拒绝有歧义的凭据；遇到这种情况，请给账号使用不同的本地代理端口。

通知说明：通知根据每个账号页面标题里的未读数生成，只显示“账号名：有 N 个未读对话”，不读取聊天内容。这个数字是“有未读消息的对话数”，所以同一个对话里连续来的新消息不会再弹通知，直到有新的对话出现未读。静音的账号不弹通知，但未读数仍计入总数。WhatsApp 网页自带的通知被关掉了，因为它看不出是哪个号发来的。

不做的事：不往 WhatsApp 页面注入脚本，不伪装画布、显卡、音频等指纹。这些对 WhatsApp 作用很小，维护成本高，而且本身容易被识别为自动化工具。

## 省内存

每个账号的 WhatsApp 网页本身大约占 300 MB，这部分省不掉。WAswitch 在不漏消息的前提下做了这些：

- **后台降级**：没在看的账号设为后台页面，Chromium 会降低它的优先级、节流定时器、释放画面缓存。消息由服务器推送，照常接收。
- **自动回收**：WhatsApp 网页开久了内存会越涨越多。后台账号超过 1024 MB、没有未读消息、并且在后台待了 30 分钟以上时，会自动在后台刷新一次（同一个号至少隔 60 分钟）。刷新只要几秒，期间的消息会从手机同步过来。可以在设置或托盘菜单里关掉，阈值可选 600 / 800 / 1024 / 1500 / 2000 MB。
- **省内存模式**：在设置或托盘菜单里打开后关闭显卡加速，整体再省一些内存，代价是动画没那么顺滑。重启后生效。
- **清理缓存**：设置 › 内存 › 清理缓存，清掉网页版账号可以重新下载的缓存（HTTP 缓存、显卡和代码缓存），释放磁盘空间。不清 cookie、IndexedDB、localStorage、Cache Storage，所以不会退出登录，聊天记录也还在；部分已下载的图片可能需要重新加载。轻量模式账号不受影响。
- **内存统计**：托盘菜单显示每个账号占用多少内存，托盘提示里显示总占用。这是近似值（只算每个账号的主页面进程），会比实际略低。

设置保存在用户数据目录的 `settings.json`。

## 话术和客户

右侧工作台一打开软件就展开，每次打开软件、换号、换客户都停在“翻译”页（不记上次的页）；在当前对话里切到话术或客户资料，换号或换对话前一直停在那页，填着表单时不跳；窗口不到 1000 宽时默认收起，点开才显示。窗口不到 1200 宽时侧栏自动只显示图标。顶栏的书本按钮（或 Ctrl/Cmd + Shift + K）可以收起或打开；收起后这次运行里保持收起，下次打开软件又会展开。工作台里还有下面两页。

- **话术**：存常用回复。
  - 点“复制”放进剪贴板。
  - 点“插入”等于帮你按一次 Ctrl+V，把话术贴进当前聊天框。剪贴板会被换成这段文字，也不会自动发送，发不发由你自己按。
  - 插入时如果当前账号已经变了、软件已锁定或页面没打开，就不会贴进去。
- **客户**：记名字、电话、标签、备注和下次跟进时间。
  - 默认只显示当前号的客户。
  - 到了跟进时间会弹一条提醒。提醒里只写“跟进提醒：名字”，不写电话和备注；聊天锁定时连名字也不显示。
  - 删除账号后，它的客户还在，在“显示所有号的客户”里标成“已删除的账号”。
- **导入导出**：支持 CSV 和 JSON。
  - 导入文件不能超过 1 MB，最多 5000 条。
  - 导出的 CSV 用 Excel 打开中文不乱码。以 + = - @ 开头的内容（比如电话号码）前面会加一个单引号，免得 Excel 当成公式。

## 翻译

面板的第三页是“翻译”，用大模型翻译。先在 设置 › 翻译 里添加服务商：

- 预设了腾讯混元、智谱和 OpenRouter，也可以填任何 OpenAI 兼容接口（包括本机的 Ollama）。模型名可以自己改。
- 密钥用系统加密保存（Windows DPAPI / macOS 钥匙串），界面上只显示尾号，不进导出文件和日志。
- 可以设一个备用服务商：默认的连不上、超时或服务商出错时自动用备用再试一次；密钥错、没余额时不换。
- 翻译用单独的网络连接，和任何 WhatsApp 账号都不共用代理，可选跟随系统代理、直连或指定代理。

用法：

- **发给客户**：在翻译框里写中文，选模式和目标语言，点“翻译并放进输入框”，译文直接贴进当前聊天框，和话术一样不会自动发送，检查后自己按发送。想先看一眼就点“只翻译”（Ctrl+Enter），译文可以改，再点“放进输入框”。翻译期间换了对话、换了号或锁屏，就不贴。“回译核对”会再翻回中文看看意思对不对。
- **看懂客户**：右侧“翻译”页显示当前对话收到的消息和中文译文；标签栏右边是“自动翻译”开关。换翻译模型在下面“回复”的语言旁边，或 设置 › 翻译（两处同步）。
- **选中就翻**：在聊天里选中一段文字，旁边会出现「翻译」小按钮，点一下原地弹出悬浮译文窗（右键菜单里也有「翻译」）：外文翻成中文，中文翻成客户的语言，可以复制。点聊天里别的地方、滚动或打字就收起。按钮和译文窗画在 WhatsApp 页面外面，只读选中的文字，不改页面。网页号和轻量号都有。
- **翻译模式**：每个模式是一段提示词，可以新建、修改、导入导出（最多 200 个）。提示词里可以用 `{目标语言}` 和 `{原文语言}`。
- 每个号记住自己的目标语言；客户资料里也可以填语言，从客户卡片点“翻译”就用客户的语言。当前打开的对话名字或号码对上了客户名单里填了语言的客户，目标语言也会自动换成客户的语言（面板和悬浮窗都会写“目标语言跟随客户「名字」”），手动改只管当前对话。

- **悬浮翻译**：0.5.2 起顶栏不再有地球按钮，收到消息的翻译统一在右侧工作台的“翻译”页里。
  - 悬浮窗只**读**页面上的消息文字（每 2 秒看一次当前打开的对话），不改 WhatsApp 页面，也不点任何东西。只读收到的消息，不读自己发的、引用的内容和群成员名字（页面上认不出谁发的时，再看气泡靠哪边、发送人名字对不对得上，名字只在页面里比，不带出来）。
  - 自动翻译默认开（不用确认），每个号可以在翻译页「收到的消息」右上单独关掉，关了会记住。每分钟最多 20 条，每天最多 500 条（设置 › 翻译 可以改成 100–2000），超过 1000 字的消息不自动翻。轻量模式的号也一样：收到的消息直接从软件自己的聊天记录里拿，自动翻译、存译文、每天上限都和网页号相同（图片、语音只翻说明文字）。

隐私：

- 不再弹确认，翻译的文字会直接发到设置里选的服务商。只发送要翻译的文字（和最近几条消息作参考），不带账号、电话和客户资料。
- 原文和译文不写日志、不写硬盘；“最近 20 条”只在内存里，关掉软件就没了。
- OpenRouter 默认要求只用不拿数据训练的上游服务商。
- 译文里如果出现原文没有的链接、电话或邮箱，会有黄色提醒。

数据只存在这台电脑的用户数据目录里，是明文 JSON（和 `accounts.json` 一样）：`quick-replies.json`、`customers.json`、`translate-modes.json`；服务商设置在 `translate.json`（密钥是加密的）；工作台回复框没发的草稿在 `reply-drafts.json`（每个对话一份，放进输入框、清空回复框或删号就删）。

- 不同步，也不上传。
- 不会写进日志或自检结果。
- 删除只打标记，方便以后同步；删除标记最多留 2 万条。

## 自检

设置 › 隔离自检：逐个测试每个账号的代理出口，提示走真实 IP 的号、共用同一个代理端口或出口 IP 的号、时区和出口对不上的号。

开发时还可以运行离线自检脚本（不需要联网和 WhatsApp 账号，检查时区、语言、代理、代理断开时不直连）：

```bash
npx electron scripts/check-isolation.js
```

## MCP 接口（可选，单独下载，默认关闭）

开启后，本机的 AI 客户端（Claude Desktop、Claude Code 等）可以通过 [MCP](https://modelcontextprotocol.io) 管理 WAswitch 里的账号。

MCP 不在安装包里。开启方法：设置 › AI 接口 → 点“下载”（约 0.7 MB，从 GitHub 直连下载，按安装包里带的 sha512 校验）→ 下载后打开“开启 MCP”开关。点“详细设置…”（或托盘图标右键 →“MCP 接口设置…”）会生成 Claude Code 的添加命令和 Claude Desktop 的配置，复制即可。

- MCP 文件的版本跟着软件走：软件更新后，下载过的电脑会自动在后台下配套的新文件，开关状态不变。
- 下载的文件放在软件数据目录的 `modules/mcp/` 下，每次加载前都再校验一次，对不上就删掉、不加载。
- “卸载”会关掉 MCP、断开所有 AI 客户端、删掉下载的文件和 token；各项开关的设置保留。
- 从源码运行（开发版）时直接用仓库里的 `src/mcp`，不下载。发版时 CI 用 `scripts/build-mcp.js` 打包这个文件并上传到 Release。

当前开放的工具（一层：账号管理，不读取聊天内容）：

| 工具 | 作用 |
| --- | --- |
| `list_accounts` | 列出账号：名称、是否当前显示、未读对话数、是否静音、页面状态 |
| `get_unread_counts` | 各账号未读对话数和总数 |
| `get_connection_status` | 各账号页面状态和错误说明（例如代理连不上） |
| `switch_account` | 切换到某个账号并显示窗口 |
| `add_account` | 打开“添加账号”窗口并预填名称和地区。不会直接创建：你确认代理并保存后才联网，扫码仍由你在手机上完成 |
| `rename_account` | 修改账号显示名称 |
| `remove_account` | 删除账号；软件会弹窗让你确认，2 分钟没人确认视为取消；同一时间只会有一个确认框 |

第二层：读对话（默认关闭，在“MCP 接口设置”里单独打开）

| 工具 | 作用 |
| --- | --- |
| `list_chats` | 读某个账号左侧对话列表里已经显示的对话：名称、未读数、时间、置顶、静音、是否群组 |
| `search_chats` | 按名字或手机号在所有账号（或指定账号）里找对话。网页版账号只搜列表顶部已显示的对话，轻量模式账号搜本机保存的全部对话。名字不分大小写和重音，0049 / +49 / 0151 这类号码写法都能找到 |
| `read_messages` | 读某个对话最近的消息（默认 20 条，最多 50 条）：文字、时间、是不是自己发的。网页版账号只能读当前打开的那个对话；轻量版账号可以按对话名称或手机号读任意已有对话 |

- 只读：在隔离环境里读页面文字，不点开对话、不滚动、不标已读、不改页面。只能读到列表顶部已经显示的对话（通常 15 到 25 个），归档的对话不在里面。
- 每次读取都会弹窗确认：拒绝 / 允许这一次 / 10 分钟内允许。“10 分钟内允许”只对这一个连接、这一个账号有效，可以在设置里随时撤销；`search_chats` 搜几个账号只弹一个确认框，已经允许过的账号不再问；打开预览、账号掉线、关闭第二层或重启软件都会清掉。2 分钟不选视为拒绝。同一账号每 5 秒最多读一次。
- 最后一条消息预览另有开关，默认关闭。
- 读到的内容会发给你用的 AI 服务商，但不会保存到电脑上。设置窗口只记录谁、什么时候、读了哪个号（或搜了什么）、几个对话（只在内存里）。
- 对话名称和预览是聊天对方写的文字，工具说明里提醒了 AI 这些只是数据，不是指令。
- `read_messages` 每次也弹窗确认，弹窗写明会读到消息内容、读哪个对话、几条。它的“10 分钟内允许”和读对话列表分开记。网页版不点开别的对话、不滚动，只读页面上已经加载的消息；你确认期间换了对话就不读。轻量版从本机聊天缓存读，不标已读、不发已读回执。记录只记谁、哪个号、几条。

起草回复（默认关闭，在“MCP 接口设置”里单独打开）

| 工具 | 作用 |
| --- | --- |
| `draft_reply` | 把一条写好的回复放进某个账号、某个对话的输入框。不发送，发送由你自己按 |

- 永远不发送：不按回车、不点发送、不模拟按键。一次只能起草一条，没有批量参数；上一条还在等你处理时，新的直接被拒绝。
- 只有这个号正显示着、窗口开着没锁、你 30 秒内没打字、要回的对话正开着、输入框是空的，才直接放进去。其他情况在窗口顶部给你看草稿，你点“放进输入框”才放（会切到这个号；轻量模式还会打开那个对话，网页版要你自己在 WhatsApp 里打开）。横幅 5 分钟没人点就消失。
- 网页版和侧栏“插入”一样借用剪贴板粘贴，不往 WhatsApp 页面注入脚本；放之前只读确认对话名称或号码对得上，放完确认草稿出现后把剪贴板换回原样。轻量模式直接填进软件里的输入框，不碰剪贴板。
- 草稿内容不保存；设置窗口只记录谁、什么时候、给哪个对话起草了几个字（只在内存里）。

读完整聊天记录需要点开对话，会标为已读，暂不提供。发消息、群发不通过 MCP 提供。

安全措施：

- 只监听 `127.0.0.1`，只接受本机连接；`Host` 头只接受 `127.0.0.1` 或 `localhost`，防止 DNS 重绑定。
- 浏览器网页发起的请求（带 `Origin` 头）一律拒绝。
- 每个请求都要带随机 token。token 和端口保存在软件数据目录下的 `mcp-token.json`，只有本人可读（0600）。关闭 MCP 时删除这个文件，重新开启或点“断开全部并更换 token”时换新 token。
- 设置窗口里的 token 是打码显示的，点“复制命令”才会复制真实 token。注意 Claude Code 会把 token 保存在它自己的配置文件里；换 token 后要用新命令重新添加。
- Windows 上 0600 权限不起作用，token 文件靠用户目录本身的权限保护（其他 Windows 用户读不到）。
- 设置窗口显示当前已连接的客户端和调用次数。
- 关闭时不加载任何 MCP 代码，不占内存。

Claude Desktop 只支持 stdio，所以通过桥接程序（下载的 MCP 文件加 `--waswitch-mcp-bridge` 参数运行，源码在 `bin/waswitch-mcp.js`）。它每次连接时从 `mcp-token.json` 读最新的 token，换 token 后不用改配置。

自检（不需要 Electron 和 WhatsApp 账号）：

```bash
npm run check:mcp
npm run check:wa-page   # 用模仿 WhatsApp 结构的测试页检查读取对话列表是否正确、是否只读（需要 Electron）
npm run check:draft     # 起草回复：草稿真的放进网页版和轻量模式的输入框、没有发送、剪贴板换回原样（需要 Electron）
```

## 打包安装包

```bash
npm run dist
```

产物在 `dist/` 目录。

推送 `v` 开头的 tag（例如 `v0.2.0`）时，GitHub Actions 会自动打包 Windows 和 macOS 安装包并发布到 Releases（标为预发布）。

自动更新依赖这一步上传的 `latest.yml`、`latest-mac.yml` 和 `.blockmap`。发布新版时：先改 `package.json` 的 `version`（必须比上一版大，更新只升不降），再推送同名 tag（带 `v`）。不要手动往 Release 里传安装包。建议给 GitHub 账号开两步验证并保护 `v*` tag：能发布 Release 就等于能给所有电脑装软件。
