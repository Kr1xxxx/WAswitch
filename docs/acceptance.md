# 真机验收清单

在一台真实的电脑上逐项检查。每项后面写“通过”或遇到的问题。出问题时，把 设置 › 关于 › 打开日志文件夹 里今天的日志文件一起发过来。

建议先用一个不重要的号测试 1–7 项。

| # | 怎么做 | 应该看到 |
| --- | --- | --- |
| 1 | 安装后第一次打开 | 欢迎页，只有“添加第一个账号” |
| 2 | 添加账号，不填代理，保存 | 右边出现 WhatsApp 二维码，手机扫码后能正常收发消息 |
| 3 | 完全退出（托盘菜单 › 退出）再打开 | 不用重新扫码，直接进入聊天 |
| 4 | 再双击一次 WAswitch 图标 | 不会开第二个，已开的窗口跳到前面 |
| 5 | 在 Clash 里按 docs/clash.md 开 7891 端口，添加第二个账号填 `socks5://127.0.0.1:7891`，点“测试” | 显示出口 IP 和国家，时区和语言自动选好 |
| 6 | 第二个账号扫码登录 | 能正常收发消息；侧栏显示国家和端口 |
| 7 | 用别的手机给两个号各发一条消息，同时停留在另一个号上 | 弹出通知，标题是收到消息的那个号的名字；点通知切到那个号 |
| 8 | 关掉窗口 | 缩到托盘，再发消息仍然有通知；托盘菜单能看到每个号的未读和内存 |
| 9 | 关掉 Clash，然后点第二个账号顶栏的刷新 | 刷新前页面上只有 WhatsApp 自己的“电脑未连接”提示；刷新后显示“代理连不上”，**不会**改用直连 |
| 10 | 重新打开 Clash，等最多 1 分钟 | 第二个账号自动恢复，不用手动点 |
| 11 | 让电脑睡眠几分钟再唤醒 | 所有账号自动恢复在线 |
| 12 | 设置 › 隔离自检 › 开始检查 | 直连的号显示黄色提醒；两个号如果用了同一个端口显示红色 |
| 13 | 设置 › 通用 › 打开“开机自动启动”，然后重启电脑 | WAswitch 自动启动并缩在托盘里，不弹窗口 |
| 14 | 按 Ctrl+1、Ctrl+2（Mac 用 Cmd） | 切换到第 1、第 2 个账号 |
| 15 | 删除一个测试账号 | 先弹确认；删除后侧栏里没有了。手机的“已关联的设备”里可能还显示这台电脑，在手机上手动退出即可 |
| 16 | 开着 4 个以上账号用一天 | 记下设置 › 内存 里的总占用，后台账号超过 800 MB 会自动刷新一次 |
| 17 | 托盘 › MCP 接口设置 › 开启，复制 Claude Code 命令并在终端运行，然后让 Claude 列出账号 | 列出的账号名称、未读数和侧栏一致 |
| 18 | MCP 设置里打开“第二层：读对话列表”，让 Claude 读某个号的对话列表，弹窗选“允许这一次” | 返回的对话和屏幕左侧列表逐项一致：名称、未读数、置顶、群组；页面没有任何变化，没有对话被标为已读 |
| 19 | 在那个号的搜索框里输入几个字，再让 Claude 读一次 | 返回里 `filtered` 为 `true` |
| 20 | 让 Claude 读对话列表，弹窗选“拒绝”，马上让它再读一次 | 不再弹窗，Claude 收到“刚拒绝过，60 秒后再试” |

## 轻量模式（小号）

**只用不重要的号测试，并且先连续用两周。** 轻量模式不是官方客户端，封号通常发生在几天到几周内。

| # | 怎么做 | 应该看到 |
| --- | --- | --- |
| 21 | 编辑主号 | “这是主号”已勾选且不能取消；添加账号时如果勾了主号，“轻量模式”按钮是灰的 |
| 22 | 添加账号，选“轻量模式”，不勾风险确认就保存 | 提示先勾选风险确认 |
| 23 | 填一个和主号同出口的代理，测试后保存 | 拒绝保存，提示出口 IP 和主号相同 |
| 24 | 填一个不同出口的 Clash 端口，测试通过后保存 | 右边显示二维码；手机扫码后出现对话列表 |
| 25 | 用别的手机发一条消息 | 弹通知，侧栏出现未读数；此时手机上对方看到的是“已送达”，**没有**蓝色已读 |
| 26 | 点开这个对话 | 对方那边变成蓝色已读 |
| 27 | 回复一条消息；连续快速发 11 条 | 前 10 条发出，第 11 条提示“发送太快” |
| 28 | 聊天里点一个网址 | 用系统浏览器打开 |
| 29 | 关掉 Clash | 显示“代理连不上”，不会直连；打开 Clash 后 1 分钟内自动恢复 |
| 30 | 完全退出再打开 | 不用重新扫码，对话列表还在 |
| 31 | 在手机“已关联的设备”里移除这台设备 | 侧栏变红，弹通知“已退出登录”；点“重新扫码”显示新二维码 |
| 32 | 删除轻量账号 | 手机“已关联的设备”里这台设备自动消失 |
| 33 | 设置 › 内存 | 轻量账号每个只有几十 MB |
| 34 | 设置 › 隔离自检 | 显示“轻量模式：后台进程只连代理，没有出现直连” |
